● ongoing research2026 – present

            
Vision-Guided Socially Aware Navigation

            
$ ros2 launch social_nav hospital_corridor.launch.py

            
    
              
  • Camera-only assistive navigation stack, with no LiDAR or depth sensing. An Ackermann-drive robot runs in a simulated hospital corridor with hazard detection and teleoperation.
    • 
              
  • Crowds simulated with ORCA (RVO2) pedestrian nodes, plus an Open-RMF airport-terminal stress test.
    • 
              
  • Building a PPO baseline on OpenCV features and testing VLM-derived scene semantics as observations and for reward shaping. Evaluated on proxemics violations, collisions and time-to-goal.
    • 
            

            
ROS 2 HumbleGazebo FortressPPOSB3OpenCVVLMsRVO2

Fuzzy Robot Coordinator

            
$ python -m coordinator --sim mujoco --robots 3

            
    
              
  • Explainable allocator that scores robot–task suitability from battery, distance, workload, payload ratio and urgency using eight Sugeno-style fuzzy rules. Compared against a weighted mathematical baseline.
    • 
              
  • Exact one-to-one assignment that maximises urgency-weighted suitability under payload and feasibility constraints.
    • 
              
  • Runs in a MuJoCo warehouse with three diff-drive robots and battery-aware charging (suspend at 25%, recharge to 85%). Includes a browser dashboard and 17 automated tests.
    •

Inverted Pendulum on a 4-Wheel Cart

            
Real-time balancing on an ESP8266. MPU6050 readings go through a Kalman filter for angle fusion, and a PID loop drives four DC motors through an L298N. A Wi-Fi web UI lets me tune PID live, without reflashing.

Nav2 Bring-up from Scratch · ERIC Robotics

            
An internship-selection task. I built map_server, AMCL and the Nav2 servers by hand instead of using nav2_bringup, and fixed 10 starter bugs. One was a wheel separation off by 2.6 cm (a 361° command turned only ~329°). Another was a /tf flood that starved the controller (~330 → 116 msg/s after the fix). Result: AMCL error 0.02–0.26 m against ground truth, and 7 of 8 goals reached within 0.21 m.
